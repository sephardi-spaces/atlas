# Sephardi Spaces Atlas

Every migration route in the [Sephardi Spaces](https://sepharad.miami.edu) archive on one map,
with a timeline, place pages, surname search and guided stories.

Live: https://sephardi-spaces.github.io/atlas/

These files are generated. Don't edit them here: the source and instructions are in the
project's `atlas/` folder (`npm run atlas:data`, then `npm run atlas:site`, then upload the
contents of `atlas/site/` here). Guided stories live in `stories.json`.
